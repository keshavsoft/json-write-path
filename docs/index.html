1. Select Mutation Action
push Single Node
Appends column element to the table colgroup array.
unshift Single Node
Prepends column element to the start of colgroup array.
set Single Node
Directly assigns property value (e.g. table CSS class).
pushToRows Row Fan-out
Deep-clones and appends action cell into every row children.
unshiftSerialToRows Row Fan-out
Prepends 1-based index (1, 2, 3...) to each data row.
2. Destination Descriptor Spec

  "jsonPath": "$..*[?@.attributes['data-role'] == 'table-colgroup']",
  "filePath": ["children"],
  "action": "push"
}
