API Guide & Reference

Function signatures, TypeScript typings, parameters, and error catalog.

writePath(registry, path, value, showLog)

The primary orchestrator export. Locates the node, picks the action, applies mutation in-place, and returns the registry.

import writePath from "json-write-path";

const updatedRegistry = writePath(registry, {
    fileName: "base",
    jsonPath: "$..*[?@.attributes['data-role'] == 'table-colgroup']",
    filePath: ["children"],
    action: "push"
}, { tagName: "col", attributes: { width: "100px" } });
Parameter Type Required Description
registry Record<string, any> Yes Dictionary containing target JSON trees indexed by fileName.
path PathDescriptor Yes Descriptor containing fileName, jsonPath, dataRole, filePath, action.
value any Yes The payload to set, append, prepend, or clone into rows.
showLog boolean No Optional console debug flag.

resolveParent(registry, path, showLog)

Low-level named export. Resolves the destination node and yields parent and key handles.

import { resolveParent } from "json-write-path";

const { parent, key, target } = resolveParent(registry, pathDescriptor);

Returns { parent, key, target } where parent[key] is the exact property target to mutate.
