Architecture & Runtime Deep Dive

How json-write-path orchestrates node location, path traversal, and mutations in V6.

The 3-Act Execution Pipeline

Every call to writePath(registry, path, value, showLog) executes across three strictly segregated acts: 

// src/v6/index.js
import actions from "../v4/actions/index.js";
import resolveParent from "./resolveParent.js";
import { set } from "../v4/actions/basic.js";

const writePath = (registry, path, value, showLog) => {
    // Act 1: Resolve the exact parent object and property key
    const { parent, key } = resolveParent(registry, path, showLog);

    // Act 2: Pick the action function from catalog
    const action = actions[path.action] || set;

    // Act 3: Execute the mutation and return registry
    action(parent, key, value);
    return registry;
};

export { resolveParent };
export default writePath;

Act 1: resolveParent Detailed Lifecycle

  1. Root Tree Selection: Looks up registry[path.fileName]. If undefined, throws an explicit error: Registry entry not found: <fileName>.
  2. Destination Node Discovery:
    • If path.jsonPath is present, runs query(root, path.jsonPath, { returnArray: true }). Verifies matches.length === 1. Throws if 0 or >1 matches.
    • Else if path.dataRole is defined, delegates to backward-compatible findByRole(root, path.dataRole).
  3. Path Traversal: Clones path.filePath array, pops the final element as key, and walks down each intermediate key using Array.reduce to resolve the target parent.
  4. Return: Returns { parent, key, target }.

Version History & Evolution

Version Features & Changes
v1 - v2 Initial monolithic prototypes with rigid guard validations (now preserved in archive/).
v3 Introduced the clean decoupled 3-Act structure (resolveParent, actions, writePath).
v4 Added showLog flag for real-time console tracing of path resolution and mutations.
v5 Added jsonpathly destination query support while maintaining backward compatibility for dataRole.
v6 (Latest) Added strict single-node assertion check, updated logging handles, returned registry for method chaining, and stabilized ESM exports.
