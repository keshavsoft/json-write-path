Complete Actions Catalog

Single-node and row fan-out mutation implementations in json-write-path.

1. Basic Single-Node Actions

set(parent, key, value)

Basic • Default

Direct assignment. Replaces parent[key] = value. Used for assigning attributes, classes, titles, or single objects. 

export const set = (parent, key, value) => {
    parent[key] = value;
};

push(parent, key, value)

Basic • Array

Normalizes value into an array with toArray and appends all items to the end of parent[key]. 

export const push = (parent, key, value) => {
    parent[key].push(...toArray(value));
};

unshift(parent, key, value)

Basic • Array

Normalizes value and prepends all items to the beginning of parent[key] array. 

export const unshift = (parent, key, value) => {
    parent[key].unshift(...toArray(value));
};

2. Row Fan-Out Actions

pushToRows(parent, key, value)

Row Fan-out

Iterates over each row object in parent[key], deep-clones value using structuredClone, and appends the items to each row's children array. 

export const pushToRows = (parent, key, value) => {
    parent[key].forEach(row => {
        row.children.push(...structuredClone(toArray(value)));
    });
};

unshiftToRows(parent, key, value)

Row Fan-out

Iterates over rows in parent[key], deep-clones value, and prepends to each row's children array. 

export const unshiftToRows = (parent, key, value) => {
    parent[key].forEach(row => {
        row.children.unshift(...structuredClone(toArray(value)));
    });
};

unshiftSerialToRows(parent, key, value)

Row Fan-out • Serial

Iterates over rows in parent[key], deep-clones value, sets item.textContent = rowIndex + 1, and prepends to row.children. 

export const unshiftSerialToRows = (parent, key, value) => {
    parent[key].forEach((row, rowIndex) => {
        const item = structuredClone(value);
        item.textContent = rowIndex + 1;
        row.children.unshift(item);
    });
};
